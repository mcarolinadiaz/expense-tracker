# Expense Tracker

A personal finance web application that helps people understand where their
money goes.

## Purpose

Keeping track of everyday spending is easy to neglect, which makes it hard to
know how much you earn, spend, and have left. Expense Tracker gives each user
one private place to record and organize their financial activity.

## Features

- **Income and expense tracking:** record each transaction with an amount, a
  date, and an optional description.
- **Custom categories:** create your own categories to match how you manage
  your money.
- **Private accounts:** each user has their own categories and transactions.

## Tech stack

- **Backend:** Laravel (REST API, with Sanctum for authentication)
- **Database:** MariaDB
- **Frontend:** Angular
- **AI assistance:** Claude, used as a development assistant
